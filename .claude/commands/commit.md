---
description: Stage and commit current changes with a concise message
allowed-tools: Bash(git *)
---

Look at `git diff` and `git status`. Write a short, plain commit message
(1 line, imperative mood, no fluff — e.g. "Add UART TX module" not
"This commit adds a new UART TX module to the project"). Stage all
relevant changes and commit. Don't ask for confirmation on the message,
just pick a reasonable one and commit — I can always amend it after.
